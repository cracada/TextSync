# TextSync

## 核心功能

- **局域网文本同步**：电脑开服务，手机/其他设备扫码打开网页，双向同步文本
- **二维码访问**：窗口显示二维码，扫码即用；左键打开网页，右键复制 URL
- **两种同步模式**
  - **打字机模式**：实时协同，输入实时同步
  - **电报模式**：显示提交，编辑完点「发送」才传，另一端点「刷新」获取，适合大文本或网络不佳等状况
- **模式切换**：网页顶部按钮随时切换，内容不丢

## 命令行参数

- `--port=端口号`：指定端口（默认 18900）
- `--telemode`：启动直接进电报模式
- `--open`：启动后直接浏览器打开URL
- `--help`：显示帮助

## 其他特性

- 端口被占用时自动往后试 20 个端口
- 单实例运行，重复双击唤出已有窗口
- ESC 关闭，数据只在内存、不落盘
- 无外网依赖，纯局域网传输

## 快捷键

- 电报模式下 **Ctrl+Enter** 发送
- 窗口内 **ESC** 关闭程序
